## Hi, I'm Your Name

I'm a software developer who enjoys turning ambiguous problems into clean, dependable
products. I care about the details users actually feel — fast pages, clear interfaces, and
code that the next person can read without a decoder ring.

I've worked across the stack, from the database up to the interface, and I'm happiest when
I can own a feature end to end: understand the problem, shape the solution, ship it, and
measure what happened.

## What I'm looking for

I'm currently open to roles where I can build products people rely on, work with a team
that values craft, and keep learning. If that sounds like your team, I'd love to talk.

## How I work

- Start from the problem, not the framework.
- Prefer boring, proven tools until they get in the way.
- Write for the next reader: clear names, small surfaces, honest tests.
- Ship in slices, watch real usage, then iterate.

## Beyond the code

Away from the keyboard I read widely, tinker with side projects, and collect half-finished
ideas. Some of the better ones end up on the [Projects](/projects) page.
