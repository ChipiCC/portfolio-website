## Hi, I'm Guillermo Rodríguez

I'm a full-stack software engineer based in Málaga, Spain. Over the past two years I've
been building fintech products at [Ebury](https://www.ebury.com/), working across the stack
in Python (FastAPI) and React, and shipping to AWS with Terraform and GitHub Actions.

I care about the parts of software that outlive the sprint: clear architecture, honest
documentation, and code the next person can read without a decoder ring. I'm also
increasingly interested in how AI and LLM-assisted workflows change the way we build — not
as a novelty, but as a real shift in how features get delivered.

## What I'm looking for

I'm open to roles where I can own features end to end — from the architecture decision
through to the deploy — on a team that values craft and keeps learning. If that sounds like
your team, I'd love to talk.

## How I work

- Start from the problem, not the framework.
- Prefer boring, proven tools until they get in the way.
- Write for the next reader: clear names, small surfaces, honest tests.
- Treat documentation and code review as part of the work, not an afterthought.
- Ship in slices, watch real usage, then iterate.

## Beyond the code

Outside of day-to-day product work I keep exploring the intersection of software
engineering and autonomous AI systems — reading, experimenting, and building small things
to see where the boundary actually sits. Some of those experiments end up on the
[Projects](/projects) page.
